Η παρούσα εργασία υλοποιεί ένα σύστημα ανταλλαγής μηνυμάτων βασισμένο στο πρότυπο request reply.
Η επικοινωνία πραγματοποιείται μέσω Sockets και υποστηρίζει ταυτόχρονη εξυπηρέτηση πολλαπλών πελατών με χρήση Threads.

ΚΛΑΣΗ ACCOUNT
username: το όνομα χρήστη
authToken: μοναδικό αναγνωριστικό χρήστη
messageBox: λίστα με τα μηνύματα χρήστη

ΚΛΑΣΗ Message
id: μοναδικό αναγνωριστικό μηνύματος
receiver: παραλήπτης
sender: αποστολέας
body: μήνυμα
is Read: εάν έχει διαβαστεί ή όχι το μήνυμα

ΚΛΑΣΗ MessagingServer
Είναι ο server όπου δημιουργεί ένα νέο thread για κάθε client.
Έχει λίστα λογαριασμών όπου η αντιστοιχισή τους γίνεται με το authToken.

ΚΛΑΣΗ MessagingClient
Ο Client συνδέεται στον server, λαμβάνει ορίσματα από τη γραμμή εντολών.
Αποστέλλει ένα αίτημα και λαμβάνει απάντηση.

Υλοποιούνται οι λειτουργίες της εργασίας δηλαδή:
Create account,show accounts,send message,show inbox,read messang and delete message.

Τα δεδομένα αυτά διατηρούνται στη μνήμη του server όσο αυτός λειτουργεί όταν σταματήσει τότε τα δεδομένα του διαγράφονται.
Σε κάθε αίτημα ο client θα πρέπει να δίνει το σωστό token διαφορετικά εμφανίζεται στην οθόνη το μήνυμα "Invalid Auth Token"

Το κάθε σενάριο της εργασίας υλοποιείται ως εξής:
1)client1,client2
2)client3
3)client4,client5
4)client6
5)client7,client8
